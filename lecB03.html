16  大数の法則・中心極限定理

「サンプルサイズ \(n\) を大きくすると、何が起きるのか？」 本講義では、統計的推論を支える2つの巨大な柱である「大数の法則」と「中心極限定理」について学びます。

  • 標本サイズが十分に大きい時の性質
  • 大数の法則、中心極限定理について演習

16.1 大数の法則

Law of Large Numbers

  • サンプルサイズ \(n\) を大きくしていくと、標本平均 \(\bar{x}\) のばらつき（標準誤差）が小さくなり、標本平均 \(\bar{x}\) は母平均 \(\mu\) に限りなく近づいていくという法則です。

  • 標本の数が多い方が、その平均値は母集団の平均値に近くなる。

16.2 演習 1

コインを100枚振ってみよう

  • コインを100枚振り、それぞれ表なら 1、裏なら 0 を記録します。
  • \(n = 1\)（コイン1枚）の場合から、\(n = 100\)（コイン100枚）の場合まで、それぞれ表の出る割合（確率）を求めます。
項目 この演習での意味
母集団 無限枚のコインを振った時の結果（0 or 1）← 調べられません
母集団の平均 \(\mu\) 理論的には 0.5 になります
標本 有限枚のコインを振った時の結果（0 or 1）← 標本で調査します
標本の数（大きさ） \(n = 1\) から \(n = 100\) ← 100パターン調査します
標本平均 表の出る割合（確率）

10枚程度では表の割合が 30% や 70% に偏ることがありますが、100枚、1,000枚と増やすほど、理論的な確率である 50%（0.5）に収束していきます。

16.3 演習 2

サイコロを10,000個振ってみよう

  • サイコロを10,000個振り、出た目を記録します。
  • \(n = 1\)（サイコロ1個）の場合から、\(n = 10{,}000\)（サイコロ10,000個）の場合まで、それぞれ出た目の平均を求めます。
母集団 無限個のサイコロを振った時の結果
← 調べられません
母集団の平均 \(\mu\) 理論的には ??? になります
標本 有限個のサイコロを振った時の結果
← 標本で調査します
標本の数（大きさ） \(n = 1\) から \(n = 10{,}000\)
← 10,000パターン調査します
標本平均 出た目の平均

出る目の平均は、試行回数が増えるほど理論上の期待値である \(3.5\) に近づきます。

16.4 中心極限定理

Central Limit Theorem: CLT

母集団がどのような分布であっても、そこから抽出した標本の「平均値」の分布は、サンプルサイズ \(n\) が十分に大きければ正規分布に近づくという定理です。

16.4.1 CLTの驚くべき特徴

元の分布を問わない

母集団が「一様分布」でも「二項分布」でも、あるいは「非常に偏った分布」であっても構いません。

図解：統計ブログ

16.4.2 なぜこれが重要なのか？

中心極限定理があるおかげで、私たちは母集団の正確な形を知らなくても、サンプルサイズさえ十分に大きければ（一般に \(n \ge 30\) 程度が目安）、正規分布を前提とした統計的推測（信頼区間の計算や仮説検定）を行うことができるのです。

16.5 演習 3

中心極限定理

  • 以下のように標本の大きさ（\(n\)）（サンプルサイズ）が異なる調査を実施し、それらの標本平均の分布を求めます。

  • この「標本平均の分布」は、\(n\) が十分に大きい場合には（一回に振るサイコロの数が多い場合には）、正規分布に近くなります。


  • \(n = 1\)（サイコロ1個）の標本で1,000回調査した場合
  • \(n = 2\)（サイコロ2個）の標本で1,000回調査した場合
  • \(n = 10\)（サイコロ10個）の標本で1,000回調査した場合
  • \(n = 30\)（サイコロ30個）の標本で1,000回調査した場合


正規分布に近づくかどうかを決めるのは、1回の調査で振るサイコロの数 \(n\) です。調査を繰り返す回数（ここでは1,000回）は、分布の形を描くためのものです。


実際にサイコロを振るのは難しいので、エクセルで擬似的にサイコロを振ります（ランダムな1から6のデータを生成します）。そして、その平均値がどのように振る舞うかを視覚化します。

  1. 乱数の生成: =RANDBETWEEN(1, 6) を使って、1から6までの整数をランダムに生成します。
  2. 平均値の算出: 異なる標本の大きさ（\(n\)）（サンプルサイズ）（\(n=1, n=2, n=10, n=30\)）で標本平均を1,000回ずつ計算します。
  3. ヒストグラムの作成: 計算した標本平均の分布をヒストグラムで描き、山型の正規分布に近づく様子を確認します。


コードを表示 
viewof k = Inputs.select([1, 2, 3, 5, 10, 30, 100, 1000], {value: 1, label: "サイコロ数 n"})
viewof reps = Inputs.select([1, 100, 1000, 10000], {value: 1, label: "繰り返し回数"})
viewof speed = Inputs.select(new Map([["1回ずつ", 1], ["10回ずつ", 10], ["100回ずつ", 100]]),
                             {value: 1, label: "表示の速さ"})
viewof go = Inputs.button("サイコロを振る", {
  value: null,
  reduce: () => ({k: k, reps: reps, speed: speed})
})
コードを表示 
sims = {
  // ボタンが押されるまでは空のまま
  if (go === null) {
    yield {i: 0, last: null, meanOfMeans: null, w: 1 / k, data: []};
    return;
  }
  const n = go.k;
  const w = Math.max(1 / n, 0.02);  // 棒の幅（n が大きいときは 0.02 ごとにまとめる）
  const counts = new Map();
  let last = null;
  let total = 0;  // 標本平均の合計
  for (let i = 1; i <= go.reps; i++) {
    let s = 0;
    for (let j = 0; j < n; j++) s += Math.floor(Math.random() * 6) + 1;
    last = s / n;
    total += last;
    const key = Math.round(last / w);
    counts.set(key, (counts.get(key) || 0) + 1);
    if (i % go.speed === 0 || i === go.reps) {
      yield {
        i: i,
        last: last,
        meanOfMeans: total / i,
        w: w,
        data: Array.from(counts, ([key, c]) => ({v: key * w, n: c}))
      };
    }
  }
}
