22  単回帰分析

ある変数が、別の変数をどのくらい説明できるかをどう調べるか？

・単回帰分析の考え方、分析方法
・回帰直線の導出、エクセルのデータ分析機能「回帰分析」を用いた分析、決定係数、回帰係数の検定、結果の解釈

22.1 散布図への直線の当てはめ

回帰分析では、2変数の一方を従属変数・被説明変数（\(y\)）、他方を独立変数・説明変数（\(x\)）とよび、因果関係を想定します（厳密な因果関係ではなく、あくまでも「想定」です）。

回帰分析で求める直線の傾きは、独立変数・説明変数（\(x\)）が1単位増えたときの、従属変数・被説明変数（\(y\)）の変化を示します。

例えば、上の図の直線 \(y = 2.0886x + 87.721\) は、「月の平均気温が1度高いと、ビールの出荷量が約2.09（100万リットル）多い」という関係を表しています。

ただし、この傾きが統計的に意味のある（有意な）ものかどうかは、後で説明する「回帰係数の検定」で確かめる必要があります。この例の結論は、回帰分析の結果の解釈で説明します。

22.2 最小二乗法（Ordinary Least Squares: OLS）

散布図の点の間に、どのように直線を引けば良いでしょうか。

  • 実際の値 \(y_i\) と、直線上の値 \(\hat{y}_i\)（予測値）の差 \(e_i\) を残差と呼びます。
  • 最小二乗法は、この残差の二乗の総和が最小になるように直線を引く方法です。

\[ y_i = a + b x_i + e_i, \qquad \hat{y}_i = a + b x_i \]

残差の二乗の総和は、次のように表されます。

\[ \sum_{i=1}^{n} e_i^2 = \sum_{i=1}^{n}(y_i - a - b x_i)^2 \]

これを最小にする \(a\) と \(b\) は、次の式で求められます（導出は参考URLを参照してください）。

\[ b = \frac{s_{xy}}{s_x^2} = \frac{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2}, \qquad a = \bar{y} - b\bar{x} \]

  • \(a\) は切片で、\(x = 0\) のときの \(y\) の値です。
  • \(b\) は回帰係数（傾き）で、\(x\) が1増えたときの \(y\) の変化量です。

22.4 回帰係数の計算（ビールの例）

ビールの出荷量を被説明変数（\(y\)）、平均気温を説明変数（\(x\)）として、回帰直線を計算します（演習ファイルの「練習_2」シートと同じ計算です）。

  • 平均気温の平均：\(\bar{x} = 16.925\)
  • ビール出荷量の平均：\(\bar{y} = 123.070\)
  • \(\displaystyle\sum_{i=1}^{12}(x_i - \bar{x})^2 = 743.203\)
  • \(\displaystyle\sum_{i=1}^{12}(x_i - \bar{x})(y_i - \bar{y}) = 1552.234\)

\[ b = \frac{1552.234}{743.203} = 2.089, \qquad a = \bar{y} - b\bar{x} = 123.070 - 2.089 \times 16.925 = 87.721 \]

したがって、回帰直線は \(\hat{y} = 87.721 + 2.089x\) となり、散布図に表示された近似曲線の式と一致します。

22.5 回帰直線のデータへの当てはまりのよさ（決定係数）

回帰直線が、データにどのくらい当てはまっているかを考えます。各データの \(y_i\) と平均 \(\bar{y}\) との差（全変動）は、回帰直線で説明できる部分（回帰変動）と、説明できない部分（残差変動）に分けられます。

これらをすべてのデータについて二乗して合計すると、次の関係が成り立ちます。

\[ \text{全変動} = \text{回帰変動} + \text{残差変動} \]

\[ \sum_{i=1}^{n}(y_i - \bar{y})^2 = \sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2 + \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 \]

両辺を全変動で割ると、

\[ 1 = \frac{\displaystyle\sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2}{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2} + \frac{\displaystyle\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2} \]

となります。この右辺の1つ目の項が決定係数（\(R^2\)）です。

\[ R^2 = \frac{\displaystyle\sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2}{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2} = 1 - \frac{\displaystyle\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2} \]

\[ \text{決定係数}（R^2）= \frac{\text{回帰変動}}{\text{全変動}} = 1 - \frac{\text{残差変動}}{\text{全変動}} \]

  • 決定係数は、データに対する、推定された回帰式の当てはまりの良さ（度合い）を表します。
  • 決定係数は一般に \(R^2\) で示され、0から1までの値をとります。
  • 1に近いほど、回帰式が実際のデータに当てはまっていることを表しており、説明変数が被説明変数をよく説明しています。
  • \(R^2 = 1\) のときには、すべてのデータが直線上に並んでいます。

ビールの例

\[ R^2 = \frac{\text{回帰変動}}{\text{全変動}} = \frac{3241.958}{13559.515} = 0.239 \]

ビールの出荷量のばらつきのうち、平均気温で説明できるのは約24%ということになります。

22.6 決定係数の例

左から \(R^2 = 0.30\)、\(0.60\)、\(0.90\) です。\(R^2\) が大きいほど、点が回帰直線の近くに集まっていることが分かります。

22.7 相関関係の強さ（復習）

22.8 決定係数（\(R^2\)）と相関係数 \(r_{xy}\) の関係

  • 決定係数：\(y\) のばらつきのうちの、回帰直線で説明できる部分の割合です。回帰直線の当てはまり具合を表します。

\[ R^2 = \frac{\displaystyle\sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2}{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2} = 1 - \frac{\displaystyle\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2} \]

  • 相関係数：2つの変数の関係の強さを、具体的な数値で表したものです。

\[ r_{xy} = \frac{s_{xy}}{s_x s_y} = \frac{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2}\sqrt{\displaystyle\sum_{i=1}^{n}(y_i - \bar{y})^2}} \]

  • 決定係数が \(R^2\) と表されるのには理由があり、実は（単回帰分析のときは）相関係数の2乗に等しくなっています。
    • ビールの例では、相関係数 \(r = 0.489\) で、\(0.489^2 = 0.239\) が決定係数と一致します（エクセルの出力の「重相関 R」が相関係数にあたります）。
  • 決定係数と相関係数は似ていますが、目的が異なります。
    • 相関関係を見る場合には、相関係数を使います。
    • 回帰式の当てはまり具合を見る場合は、決定係数を使います。
  • 例えば、相関係数0.7というと強い正の相関があると言えそうですが、決定係数で考えると0.7を2乗するので0.49になり、「相関関係はありそうだけど、回帰式の当てはまり具合（説明力）はそれほど高くない」となります。
Note証明：決定係数は相関係数の2乗に等しい（単回帰分析の場合）

\(S_{xx} = \sum(x_i - \bar{x})^2\)、\(S_{yy} = \sum(y_i - \bar{y})^2\)、\(S_{xy} = \sum(x_i - \bar{x})(y_i - \bar{y})\) とおくと、\(b = \dfrac{S_{xy}}{S_{xx}}\)、\(r_{xy} = \dfrac{S_{xy}}{\sqrt{S_{xx}}\sqrt{S_{yy}}}\) です。

ステップ1： \(a = \bar{y} - b\bar{x}\) より、回帰直線は平均の点 \((\bar{x}, \bar{y})\) を通るので、

\[ \hat{y}_i - \bar{y} = (a + b x_i) - (a + b\bar{x}) = b(x_i - \bar{x}) \]

ステップ2： 回帰変動は、

\[ \sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2 = b^2 S_{xx} = \left(\frac{S_{xy}}{S_{xx}}\right)^2 S_{xx} = \frac{S_{xy}^2}{S_{xx}} \]

ステップ3： したがって、

\[ R^2 = \frac{\text{回帰変動}}{\text{全変動}} = \frac{S_{xy}^2}{S_{xx} S_{yy}} = \left(\frac{S_{xy}}{\sqrt{S_{xx}}\sqrt{S_{yy}}}\right)^2 = r_{xy}^2 \]

ビールの例：\(R^2 = \dfrac{1552.234^2}{743.203 \times 13559.515} = 0.239 = 0.489^2\)

22.9 回帰係数 \(b\) と相関係数 \(r_{xy}\) の関係

  • 回帰係数：回帰直線における傾き（\(x\) の値が1増えた場合の \(y\) の変化量）です。

\[ b = \frac{s_{xy}}{s_x^2} = \frac{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2} \]

  • 回帰係数と相関係数には、次の関係があります。

\[ b = \frac{s_{xy}}{s_x^2} = \frac{s_{xy}}{s_x s_y} \cdot \frac{s_y}{s_x} = r_{xy} \cdot \frac{s_y}{s_x} \]

  • つまり、回帰係数の符号（プラスかマイナスか）は、相関係数の符号と必ず一致します。
  • ただし、回帰係数の大きさは \(x\) と \(y\) の単位によって変わるので、回帰係数が大きいからといって、相関が強いとは限りません。

22.10 再び推定

推定とは、母集団の特徴を標本から推測することでした。回帰分析でも、標本から計算した回帰式（標本回帰式）を使って、母集団の回帰式（母集団回帰式）を推定します。

\[ \text{母集団回帰式：} y_i = \alpha + \beta x_i + \varepsilon_i \qquad \text{標本回帰式：} y_i = a + b x_i + e_i \]

同じ母集団から取った標本でも、標本が違えば、計算される回帰直線（\(a\) や \(b\)）も変わります。

\(a\)、\(b\)、\(e_i\) は、その時に取得した標本によって変わる確率変数です。そのため、誤差を計算して検定を行い、回帰直線が右上がりなのか、右下がりなのか、横一直線（関連がない）なのかを判断します。

22.11 標本によって回帰係数が変わる様子

母集団の回帰式が \(y = 90 + 2x + \varepsilon\)（\(\varepsilon\) の標準偏差は32）であるとして、ビールのデータと同じ12個の気温で、何度も標本を取り直してみます。母集団の傾きは \(\beta = 2\) ですが、標本から計算した \(b\) は、標本ごとに変わります。

コードを表示 
viewof nDraw = Inputs.select(new Map([["1回", 1], ["10回", 10], ["100回", 100]]), {value: 1, label: "取り直す回数"})
viewof goB = Inputs.button("標本を取り直す")
コードを表示 
mutable bList = []

simSample = {
  goB;
  const xs = beer.map(d => d.x);
  const alpha = 90, beta = 2, sigma = 32;
  const randn = () => {
    let u = 0, v = 0;
    while (u === 0) u = Math.random();
    while (v === 0) v = Math.random();
    return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v);
  };
  const fit = pts => {
    const n = pts.length;
    const mx = d3.mean(pts, d => d.x), my = d3.mean(pts, d => d.y);
    const sxx = d3.sum(pts, d => (d.x - mx) ** 2);
    const sxy = d3.sum(pts, d => (d.x - mx) * (d.y - my));
    const b = sxy / sxx, a = my - b * mx;
    const sse = d3.sum(pts, d => (d.y - a - b * d.x) ** 2);
    const se = Math.sqrt(sse / (n - 2) / sxx);
    return {a, b, se, t: b / se};
  };
  let last = null;
  const newFits = [];
  for (let k = 0; k < nDraw; k++) {
    const pts = xs.map(x => ({x: x, y: alpha + beta * x + sigma * randn()}));
    const f = fit(pts);
    newFits.push(f);
    last = {pts, ...f};
  }
  mutable bList = mutable bList.concat(newFits);
  return last;
}

sigShare = d3.mean(bList, d => Math.abs(d.t) > 2.228 ? 1 : 0)

22.12 回帰係数の検定

  • 母集団回帰式：\(y_i = \alpha + \beta x_i + \varepsilon_i\)
  • 標本回帰式：\(y_i = a + b x_i + e_i\)

\(b\) は、次の正規分布に従います（\(\sigma^2\) は \(\varepsilon\) の分散）。

\[ b \sim N\left(\beta, \ \frac{\sigma^2}{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2}\right) \]

\(\sigma^2\) は分からないので、残差 \(e\) の分散 \(\left(\dfrac{1}{n-2}\displaystyle\sum_{i=1}^{n} e_i^2\right)\) で置き換えて標準化すると、次の検定統計量は自由度 \(n - 2\) の \(t\) 分布に従います。

\[ t = \frac{b - \beta}{\sqrt{\dfrac{\frac{1}{n-2}\displaystyle\sum_{i=1}^{n} e_i^2}{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2}}} \]

分母は \(b\) の標準偏差であり、一般に標準誤差（Standard Error: SE）と呼ばれます。

\[ SE(b) = \sqrt{\frac{\frac{1}{n-2}\displaystyle\sum_{i=1}^{n} e_i^2}{\displaystyle\sum_{i=1}^{n}(x_i - \bar{x})^2}} \]

詳しい証明は、単回帰分析（統計太郎）を参照してください。

22.13 回帰係数の検定の手順

これまでに学んだ仮説検定の手順に沿って、回帰係数の検定を行います。

手順1：仮説を設定する

  • 帰無仮説（\(H_0\)）：\(\beta = 0\)（\(x\) は \(y\) と関係しない。母集団の回帰直線は横一直線）
  • 対立仮説（\(H_1\)）：\(\beta \neq 0\)（\(x\) は \(y\) と関係する）

検定するのは、標本から計算した \(b\) ではなく、母集団の係数 \(\beta\) です。\(b\) が0かどうかは計算すればすぐに分かりますが、知りたいのは、母集団で \(x\) と \(y\) に関係があるかどうかだからです。

手順2：有意水準（臨界値）を決める

有意水準は5%（両側検定）とします。

手順3：検定統計量 \(t\) を求める

帰無仮説により \(\beta = 0\) なので、検定統計量は次のようになります。

\[ t = \frac{b - \color{#E36C09}{\beta}}{SE(b)} = \frac{b - \color{#E36C09}{0}}{SE(b)} = \frac{b}{SE(b)} \]

これが自由度 \(n - 2\) の \(t\) 分布に従うことを使って検定します。

Note回帰分析の検定の考え方（まとめ）
  1. データを入手します。
  2. \(Y\)（被説明変数）と \(X\)（説明変数）となる関係の変数を検討します。
  3. \(Y\) と \(X\) の関係が式で表されます：\(Y_i = a + b x_i + e_i\)
  4. この係数 \(b\) は今回の標本から得た値なので、標本が変われば、いろいろな値を取ります。つまりは、とりえる値の範囲があります。
  5. この範囲にゼロを含むかどうか（母集団の係数 \(\beta\) がゼロであっても、今回のような \(b\) が出てくるかどうか）を検定します（帰無仮説は \(\beta = 0\)）。
  6. 検定統計量は、\(b\) を標準誤差（SE）で割った \(\dfrac{b}{SE(b)}\) を用い、これが自由度 \(n - 2\) の \(t\) 分布に従うことで検定します。
  7. 係数の大きさは、\(Y\) と \(X\) の関係の大きさを表します。

22.15 回帰分析の結果の解釈

手順4：検定統計量と臨界値を比較する　手順5：検定の結論を出す

係数の値の読み方

  • 回帰直線は \(\hat{y} = 87.721 + 2.089x\) です。
  • 回帰係数 \(b = 2.089\) は、「月の平均気温が1度高いと、ビールの出荷量が約2.09（100万リットル）多い」という関係を表しています。
  • 切片 \(a = 87.721\) は、平均気温が0度のときのビールの出荷量の予測値です（ただし、データには平均気温0度の月がないので、切片そのものに大きな意味はありません）。
  • 決定係数は0.239なので、ビールの出荷量のばらつきのうち、平均気温で説明できるのは約24%です。

回帰係数の検定

  • \(t = 1.773\)、自由度 \(n - 2 = 10\)、有意水準5%（両側）の臨界値：2.228
  • P値：0.107
  • \(t = 1.773\) は臨界値2.228より小さく、P値0.107は有意水準0.05より大きいので、帰無仮説（\(\beta = 0\)）は棄却されません。
  • 回帰係数の95%信頼区間（\(-0.537\) 〜 \(4.714\)）も0を含んでおり、この結果と一致しています。

結論

  • 回帰係数はプラス（2.089）ですが、有意水準5%では統計的に有意ではありません。
  • つまり、「このデータからは、平均気温とビールの出荷量に関係があるとはいえない（有意水準5%）」という結論になります。
  • 「係数の値がいくつか」と「その係数が統計的に有意かどうか」は、分けて読むことが大切です。係数の値だけを見て、「気温が1度上がると出荷量が2.09増える」と結論づけることはできません。
Noteなぜ有意にならなかったのか？（外れ値の影響）
  • 散布図（図 22.1）を見ると、平均気温が9.9度と低いのに、ビールの出荷量が185.3と最も多い点があります。これは12月のデータで、年末の忘年会や贈答などの需要によるものと考えられます。
  • 試しに12月を除いた11か月で計算すると、回帰係数は \(b = 2.944\)、決定係数は \(R^2 = 0.640\)、P値は0.003となり、有意水準5%で有意になります。
  • このように、1つの外れ値が結果を大きく変えることがあります。8回目講義の「留意点 2：必ず散布図を確認する」と同じことが、回帰分析でも起こります。
  • ただし、都合の悪いデータを勝手に除いて分析してはいけません。12月には「年末の需要」という気温以外の要因があるので、本来は、その要因も説明変数として加えて分析するべきです。これは、次回以降の重回帰分析や、質的情報（ダミー変数）の分析で扱います。
  • また、データが12個しかないことも、有意になりにくい理由の一つです（上の「標本によって回帰係数が変わる様子」のシミュレーションを参照）。
Note回帰係数の検定と相関係数の検定の関係
  • 8回目講義の相関係数の検定の式に、ビールの例の \(r = 0.489\)、\(n = 12\) を入れると、次のようになります。

\[ t = \frac{r\sqrt{n - 2}}{\sqrt{1 - r^2}} = \frac{0.489 \times \sqrt{10}}{\sqrt{1 - 0.239}} = 1.773 \]

  • これは、回帰係数の検定の \(t\) 値（1.773）と一致します。
  • つまり、単回帰分析の回帰係数の検定は、相関係数の検定と同じことをしています（P値も同じ0.107になります）。

22.16 エクセルでの計算方法

演習ファイルの「練習」シートのように、B列に月、C列に平均気温（C6〜C17）、D列にビール出荷量（D6〜D17）が入力されているとします（セルの位置は、シートに合わせて読み替えてください）。

散布図に回帰直線・数式・決定係数を表示する方法（練習_1）

  1. 平均気温とビール出荷量のデータ（C6:D17）を選択し、「挿入」→「散布図」を選びます（左の列が \(x\) 軸、右の列が \(y\) 軸になります）。
  2. グラフの点を右クリックし、「近似曲線の追加」を選びます。
  3. 「線形近似」を選び、「グラフに数式を表示する」と「グラフに R-2 乗値を表示する」にチェックを入れます。
  4. グラフに回帰直線と、\(y = 2.0886x + 87.721\)、\(R^2 = 0.2391\) が表示されます。

関数で計算する方法

求めるもの エクセルの式 結果
回帰係数（傾き） \(b\) =SLOPE(D6:D17, C6:C17) 2.089
切片 \(a\) =INTERCEPT(D6:D17, C6:C17) 87.721
決定係数 \(R^2\) =RSQ(D6:D17, C6:C17) 0.239
相関係数 \(r\) =CORREL(C6:C17, D6:D17) 0.489
予測値（平均気温20度のとき） =FORECAST.LINEAR(20, D6:D17, C6:C17) 129.49
臨界値（両側・有意水準5%、自由度10） =T.INV.2T(0.05, 10) 2.228
P値（\(t = 1.773\) のとき） =T.DIST.2T(1.773, 10) 0.107
  • SLOPE、INTERCEPT、RSQ、FORECAST.LINEAR は、\(y\) の範囲を先に、\(x\) の範囲を後に指定します。順番を逆にすると、\(x\) を \(y\) で回帰した別の結果になるので注意してください。
  • 定義の式どおりに計算する場合（練習_2）は、各データについて \((x_i - \bar{x})\)、\((y_i - \bar{y})\)、\((x_i - \bar{x})^2\)、\((x_i - \bar{x})(y_i - \bar{y})\) を計算し、その合計から \(b = \dfrac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}\)、\(a = \bar{y} - b\bar{x}\) を求めます。

分析ツールの「回帰分析」を使う方法（練習_3）

  1. 「データ」→「データ分析」→「回帰分析」を選びます。
  2. 「入力 Y 範囲」に被説明変数（ビール出荷量）の範囲を、「入力 X 範囲」に説明変数（平均気温）の範囲を指定します。
    • 見出しの行も含めて範囲を指定した場合は、「ラベル」にチェックを入れます。
  3. 出力先を指定して「OK」を押すと、上の「エクセルの分析結果」のような表が出力されます。

「入力 Y 範囲」と「入力 X 範囲」を逆にしないように注意してください。どちらを \(Y\)（被説明変数）、どちらを \(X\)（説明変数）にするかは、分析の目的（何が何に影響すると想定するか）で決めます。
